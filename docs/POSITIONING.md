# Positioning & Messaging

## Competitive Alternatives
Standard LTR-focused Markdown editors (VS Code, Notion, Obsidian, HackMD) which struggle with mixed Persian/English documents and invert code block orientations or mess up punctuation.

## Unique Attributes → Value Themes
| Attribute | Value ("so what") | Proof |
|---|---|---|
| Native GFM RTL Engine | Mixed Persian/English text renders with proper right-to-left flow while code blocks remain 100% LTR | Embedded regex pre-processor and remark-gfm parser |
| Local In-Browser Processing | Complete privacy and zero server latency | 0 external network calls for text processing |
| Dark Glass Studio UI | Professional writing environment optimized for long sessions | Tailored Zinc palette with WCAG AA compliance |

## Best-Fit Customer
Persian and Arabic software developers, technical writers, documentation maintainers, educators, and bloggers who need to author mixed RTL/LTR Markdown effortlessly.

## Market Category
Specialized Developer Writing Tools / RTL Markdown Editors.

## One-Liner
RTL Markdown Studio is a privacy-first, real-time Markdown editor designed specifically for Persian and Arabic technical writers.

## Brand Script (StoryBrand)
- **Character**: Technical writer or developer drafting documentation in Persian.
- **Problem**:
  - *External*: Mixed RTL/LTR text gets scrambled; code blocks break and punctuation jumps to the wrong side.
  - *Internal*: Frustration with tools that don't respect Persian/Arabic writing direction.
  - *Philosophical*: Technical documentation in any language should look pristine and professional without formatting hacks.
- **Guide**: RTL Markdown Studio with dedicated GFM direction pre-processing.
- **Plan**: Type or paste Markdown -> See live RTL preview -> Download or copy clean output.
- **Call to Action**:
  - *Direct*: Paste / Download `.md` / Copy Markdown
  - *Transitional*: "Load Sample Markdown"
- **Failure**: Ugly, unreadable documentation that alienates readers.
- **Success**: Professional, perfectly aligned RTL documentation with pristine LTR code blocks.

## Commander's Intent (Made to Stick)
"Zero-latency, 100% client-side RTL Markdown conversion that leaves code blocks completely untouched."
