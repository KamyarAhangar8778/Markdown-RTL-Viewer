# Customer & Jobs-to-be-Done

## Job Statement
When I write or read Markdown documents containing mixed Persian/Arabic (RTL) text and English/Code (LTR), I want a real-time editor and previewer that formats text direction correctly without breaking code blocks, so I can present clean, readable documentation effortlessly.

## Job Dimensions

### Functional Dimension
- Convert mixed RTL/LTR Markdown documents into well-structured RTL HTML/React previews.
- Ensure embedded code blocks, tables, inline code, and URLs remain strictly LTR and left-aligned.
- Provide live line, word, and character counts alongside read-time estimates.
- Support instant file upload (.md/.txt), clipboard paste, file download, and distraction-free focus mode.

### Emotional Dimension
- Confidence that mixed-language technical documents look clean and professional without manual RLM/LRM insertion hacky workarounds.
- Peace of mind that all text processing happens 100% locally in browser memory without sending private text to external servers.

### Social Dimension
- Ability to share beautifully formatted Persian technical guides and reports with teammates or clients.

## Competing Alternatives

| Alternative | Why Hired | Weakness |
|---|---|---|
| Standard Markdown Editors (VS Code, Notion, Obsidian) | Pre-installed or default team tool | Poor or inconsistent RTL alignment for mixed technical Persian/English content |
| Raw Text Editors (Notepad++, Sublime Text) | Lightweight and fast | No live Markdown preview or RTL auto-formatting engine |
| Manual Unicode Insertion (RLM / LRM characters) | Works in any text box | Extremely tedious, error-prone, and clutters raw Markdown source text |
