# Development Guide

## Setup & Running

1. **Install Dependencies:**
   ```bash
   npm install
   ```

2. **Start Local Development Server:**
   ```bash
   npm run dev
   ```

3. **Production Build:**
   ```bash
   npm run build
   ```

4. **Linting & Code Formatting:**
   ```bash
   npm run lint
   ```

## Guidelines for Adding Features

- Keep all files modular and concise (< 150 lines per file).
- Always include JSDoc comments for new utility functions.
- Test RTL rendering in Persian and Arabic sample documents.
