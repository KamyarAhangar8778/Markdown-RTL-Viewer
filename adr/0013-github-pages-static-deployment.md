# ADR-0013: استقرار ایستا روی GitHub Pages با خط لوله خودکار GitHub Actions

## وضعیت (Status)
پذیرفته‌شده (Accepted)

## تاریخ (Date)
۲۰۲۶-۰۹-۰۷

## زمینه و مسئله (Context)
پروژه RTL Markdown Studio بر پایه معماری حریم خصوصی بدون سرور (ADR-0008) و پردازش ۱۰۰٪ سمت کلاینت طراحی شده است. جهت در دسترس قرار دادن عمومی استودیو به شکل بدون هزینه و ایستا روی پلتفرم GitHub Pages، به ساختار خروجی ایستا (`output: 'export'`)، مدیریت مسیر پایه مخزن (`basePath`)، غیرفعال‌سازی سرور بهینه‌ساز تصاویر (`images.unoptimized`)، و جلوگیری از تداخل موتور Jekyll با فایل‌های `_next` نیاز بود.

## تصمیم (Decision)
1. **پیکربندی هوشمند Next.js (`next.config.ts`):**
   - تعیین خودکار حالت `output: 'export'` و `images.unoptimized: true` و `trailingSlash: true` هنگام استقرار در GitHub Actions یا متغیر محیطی `NEXT_EXPORT=true`.
   - دریافت خودکار `basePath` و `assetPrefix` از خروجی اکشن رسمی `actions/configure-pages` از طریق `NEXT_PUBLIC_BASE_PATH` جهت پشتیبانی یکپارچه از روت اصلی یا ساب‌پث مخزن (مانند `username.github.io/repo-name`).
2. **پایپ‌لاین خودکار CI/CD (`.github/workflows/deploy.yml`):**
   - ایجاد اکشن استاندارد استقرار روی GitHub Pages با فعال‌سازی دسترسی‌های امن OIDC (`id-token: write`, `pages: write`).
   - ساخت پکیج ایستا به پوشه `out/` و آپلود مستقیم Artifact بدون نیاز به ابزارها یا توکن‌های دستی جانبی.
3. **تولید فایل پیش‌فرض `.nojekyll`:**
   - تعبیه فایل خالی `.nojekyll` در پوشه `public/` و لمس (touch) آن در فرایند خروجی برای اطمینان از سرو صحیح باندل‌های استاتیک `_next/` توسط گیت‌هاب پیجز.
4. **اسکریپت‌های توسعه محلی:**
   - افزودن دستورات `build:export` و `deploy` (با استفاده از کتابخانه استاندارد `gh-pages`) برای استقرار دستی مستقیم از ترمینال در صورت نیاز.

## پیامدها و بده‌بستان‌ها (Consequences)
- **مزایا:** هزینه میزبانی صفر، استقرار کامپوننت‌های استودیو در سطح جهانی با CDN گیت‌هاب، انتشار خودکار با هر Push به شاخه `main` یا `master`، و حفظ کامل سازگاری با حالت Standalone در محیط‌های سروری کانتینری.
- **بده‌بستان:** عدم امکان استفاده از قابلیت‌های نیازمند سرور Node.js سنتی (مانند API Routes سروری) که از پیش با فلسفه ADR-0008 همخوانی کامل دارد.
