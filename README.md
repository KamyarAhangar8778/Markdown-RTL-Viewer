# استودیو مارک‌داون راست‌چین | RTL Markdown Studio

> محیطی متمرکز، چشم‌نواز و استاندارد برای نگارش و پیش‌نمایش اسناد مارک‌داون دوجهته (فارسی، عربی و انگلیسی) با پاسداری کامل از ساختار قطعه‌کدها و حریم خصوصی داده‌ها.

## چرا این استودیو خلق شد؟

نگارش متون تخصصی به زبان‌های راست‌چین (RTL) مثل فارسی، همواره با چالش‌های آزاردهنده‌ای همراه بوده است:
- پرانتزها و نشانه‌های نگارشی که معکوس و نامرتب می‌شوند.
- قطعه‌کدهایی که ناخواسته راست‌چین شده و چینش دستوری‌شان به هم می‌ریزد.
- جدول‌هایی که ستون‌ها و متن‌هایشان غیرقابل خواندن می‌شوند.
- و سرویس‌های آنلاینی که نوشته‌های شما را به سرورهای خارجی ارسال می‌کنند.

**RTL Markdown Studio** با این چشم‌انداز ساخته شده است که نوشتن مستندات فارسی به همان اندازه روان، تمیز و لذت‌بخش باشد که شایسته آن است؛ بدون فدا کردن حریم خصوصی، سرعت تایپ یا زیبایی بصری.

## قابلیت‌های برجسته

### ✍️ جریان متنی دوجهته هوشمند (Bi-Directional Flow)
پاراگراف‌ها، عناوین، فهرست‌ها و نقل‌قول‌ها بر اساس ماهیت متن در جهت طبیعی خود تراز می‌شوند؛ بدون آنکه سینتکس استاندارد مارک‌داون دستخوش تغییر ناخواسته شود.

### 💻 عایق‌سازی قطعه‌کدها (Zero Code Disruption)
بلاک‌های کد به طور کامل از جریان راست‌چین جدا نگه داشته شده و همواره چپ‌به‌راست (LTR)، همراه با شماره‌گذاری خطوط، هایلایت نحوی با `Highlight.js` و تایپوگرافی هماهنگ `JetBrains Mono` و `Vazirmatn` نمایش داده می‌شوند ([ADR-0003](./adr/0003-hybrid-code-typography-and-font-caching.md)).

### 🔒 حریم خصوصی مطلق (Zero-Backend Privacy)
تمام پردازش‌ها، تبدیل‌ها و محاسبات منحصراً در مرورگر شما انجام می‌شوند. هیچ سرور واسط، کوکی ردیابی یا پایگاه داده‌ای وجود ندارد و کلمات شما هرگز دستگاهتان را ترک نمی‌کنند ([ADR-0008](./adr/0008-zero-backend-client-side-privacy.md)).

### ⚡ سرعت پاسخ‌دهی ۶۰ فریم (Deferred Reactive Pipeline)
با به‌کارگیری `useDeferredValue` در React 19، تغییرات آنی تایپ شما در ادیتور با اولویت بالا و پردازش‌های سنگین موتور مارک‌داون در فاز معوق انجام می‌پذیرد تا حتی در اسناد چندهزار خطی، تایپ بدون افت فریم باقی بماند ([ADR-0010](./adr/0010-deferred-reactive-state-pipeline.md)).

### 🎯 داک شناور استودیو و تمرکز عمیق (Studio Dock & Focus Mode)
- **داک تعاملی:** نوار ابزار شناور با فیزیک فنری و افکت بزرگ‌نمایی مجاورت ماوس (مشابه داک macOS).
- **حالت تمرکز (Focus Mode):** پنهان‌سازی سریع عناصر اضافی صفحه برای نویسندگی بدون حواس‌پرتی.
- **اسکرول نرم دسکتاپ:** تجربه اسکرول اینرسی با Lenis برای کاربران ماوس دقیق ([ADR-0002](./adr/0002-desktop-only-smooth-scroll.md)).

### 📊 تحلیل زنده و شاخص‌های آماری
- شمارش دقیق کلمات، کاراکترها و خطوط با تفکیک حروف فارسی و لاتین.
- تخمین زمان مطالعه بر پایه میانگین سرعت خواندن انسان.
- نمایش ارقام با اعداد استاندارد فارسی به کمک ماژول اختصاصی `persianizer`.

### 🗂 مدیریت آسان اسناد
- بارگذاری فایل‌های `.md` با Drag & Drop یا انتخاب از حافظه.
- کپی سریع متن پردازش‌شده با یک کلیک.
- خروجی گرفتن و دانلود مستقیم فایل نهایی.

## ساختار ماژولار پروژه

پروژه با ساختاری شفاف و پایبند به اصل تک‌مسئولیتی پیاده‌سازی شده است:

```text
/
├── app/                  # روت‌ها و چیدمان اصلی Next.js App Router
├── components/
│   ├── layout/           # هدر کپسولی، داک ابزار و ارائه‌دهنده اسکرول
│   ├── views/            # ویوهای ادیتور، پیش‌نمایش و مودال‌های ورودی
│   ├── ui/               # کامپوننت‌های پایه رابط کاربری (دکمه، جدول، بلاک کد)
│   └── motion/           # انیمیشن‌ها و ترنزیشن‌های اختصاصی دیزاین‌سیستم
├── services/             # موتور خالص پردازش متن و تحلیلگر دامنه (markdownEngine)
├── store/                # کانتکست وضعیت سراسری و خط‌لوله معوق
├── hooks/                # هوک‌های سفارشی (محاسبه خط فعال، کلیپ‌بورد، شبیه‌ساز تایپ)
├── utils/                # توابع خالص کمکی (RTL Converter، آمارگیر، فارسی‌ساز)
├── constants/            # ثوابت دامنه و فرهنگ‌لغت دوزبانه (fa / en)
├── types/                # تعاریف داده و اینترفیس‌های Type-Safe
├── adr/                  # اسناد سوابق تصمیمات معماری (Architecture Decision Records)
├── docs/                 # مستندات تکمیلی، الگوها و اهداف محصول
└── tests/                # تست‌های واحد و یکپارچگی
```

## راه‌اندازی و اجرا

### پیش‌نیازها
- **Node.js:** نسخه 20 به بالا (یا موتور **Bun**)
- **npm** یا **bun**

### ۱. دریافت مخزن و نصب وابستگی‌ها
```bash
git clone https://github.com/your-username/rtl-markdown-studio.git
cd rtl-markdown-studio
npm install
```

### ۲. اجرای محیط توسعه
```bash
npm run dev
```
مرورگر خود را باز کرده و به آدرس `http://localhost:3000` مراجعه کنید.

### ۳. بررسی سلامت کد (Lint & Typecheck)
```bash
npm run typecheck    # اعتبارسنجی تایپ‌های TypeScript
npm run lint         # بازرسی استانداردهای ESLint
npm run check        # اجرای کامل بررسی تایپ، لینتر و تست‌ها
```

### ۴. بیلد بهینه‌سازی‌شده نهایی
```bash
npm run build
npm run start
```
